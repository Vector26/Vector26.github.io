01 — Architecture

One brain, 14+ roles.

Clients talk to a small HTTP gateway. Requests go through a priority queue so only one heavy model sits on the GPU at a time — no duplicate copies and less VRAM fighting.

02 — The local model

Big MoE, long context, bounded VRAM.

Weights are quantized; KV cache is compressed; experts can be staged so the active path fits consumer hardware. Exact flags and utilization are intentionally not published here.

05 — Self-healing

Checks that exercise real behavior.

Timers and cron run probes: not only “is the process up,” but can the queue serve a completion, are dependencies reachable, and do background jobs stay within policy.

VRAM policy (conceptual)

P0

Interactive brain

Last thing you tear down under pressure.

P1

Voice / latency-sensitive

Graceful exit before hard kills when possible.

P2

Batch GPU

Stopped or deferred first when the GPU is saturated.

Rhythm (categories only)

FrequentLight agent-platform probe + auto-repair of safe conditions
HourlyBroader health pass with alerting on real failures
Daily / weeklyBackups, retention, feed learning, image hygiene — as configured

Security posture (high level)

Defense in depth — without a punch list for attackers.

Private connectivity, authenticated APIs, least-privilege agents, encrypted off-site backup, and separation between “ops proposals” and “ops execution.” Details of firewall rules, backup backends, and token storage stay in private docs.
